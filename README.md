# 動画から顔写真を自動抽出（ベストショット抽出ツール）

動画から「正面を向いていて・ピントが合っていて・顔が大きい」コマを自動で選び、顔写真として保存するツールです。
iPhone / iPad（Safari）と PC のブラウザから、URL を開くだけで使えます。

## 使い方（iPhone）

1. Safari でこのページを開く
2. 「動画ファイルを選ぶ」→「写真ライブラリ」または「ファイル」から動画を選ぶ
3. 「解析スタート」を押す（画面を閉じたりロックすると止まります）
4. 候補が出たら「JPG保存」で保存。
   - 写真アプリに入れたいときは画像をタップ → 右上「共有」→「画像を保存」
   - 「すべて保存（iPhone）」は「ファイル」アプリにまとめて保存されます

## 使い方（PC）

1. ブラウザでこのページを開く
2. 動画をドラッグ＆ドロップ（またはファイルを選択）
3. 解析スタート → 候補から保存（Chrome / Edge では「フォルダに一括保存」も使えます）

## 仕組み・注意

- 顔の検出は MediaPipe Face Landmarker（ブラウザ内で実行）。動画・画像はサーバーに送信されません。
- 高画質補正（アップスケール＋アンシャープ）もすべて端末内で処理します。
- **AI超解像**（APIキー不要）: 候補の画面で「AI超解像」をONにすると、端末内のAI
  （UpscalerJS + ESRGAN-slim / TensorFlow.js webgl）で顔を2倍に高画質化します。
  - モデルとJSはすべてこのサイト内に同梱（`lib/tf.min.js`、`lib/upscaler.min.js`、
    `models/ai/esrgan-slim/x2/`）。外部CDN・APIには一切アクセスしません。
  - ONにしたときだけ読み込みます（初回 約2.5MB）。既定はOFFで、起動はこれまでと同じ軽さです。
  - ONにすると1枚目（BEST）だけ自動でお試し処理し、残りは各カードの「✨ AI超解像」か
    「✨ すべてAI超解像」で処理します（1枚ずつ順番に処理します）。
  - 拡大表示の「補正後（AI）」、JPG/PNG保存、フォルダ保存は AI超解像後の画像を使います
    （ファイル名の末尾は `_ai-sr`）。
  - メモリ不足などで失敗したときは標準の高画質補正に自動フォールバックし、日本語で案内します。
- 任意設定で fal.ai の API キーを入れた場合のみ、AI高画質化のときだけ画像が fal.ai に送信されます。
- 初回は AI モデル（約10MB）の読み込みに少し時間がかかります。
